# OneFrame NAS v1.15 变更记录

**日期**：2026-07-09

---

## 一、新增 Type N 样式

基于 Type G 演变的上下对称边框布局：

- 顶部 7.5% 白色边框（Logo 居中）
- 中部 85% 照片区（12px 圆角）
- 底部 7.5% 文字区（参数 + 署名）
- 纵向图片：顶部 3.75% + 中部 92.5% + 底部 3.75%

### 参数格式

混合字重设计：
- 标签（Aperture/Focal/Shutter/ISO）：MiSans Medium（500）
- 数值：MiSans Normal（400）
- 署名：MiSans Normal（400）

```
Aperture f/1.8  Focal 50mm  Shutter 1/100s  ISO 100
```

### 编辑面板配置

隐藏：边框颜色、边框高度、比例设置、设备型号、时间设置
保留：Logo 选择、拍摄参数、署名文字
