## 二、分阶段明细

### P1 — Type A（填满式试点）
- `type-A.css`：追加 `.frame-wrapper.type-a` 与 `.frame-wrapper.type-a > img` 的 `max-width/max-height:none !important`（`> img` 仅命中主图，避免误伤底栏 logo）
- `type-A-preview.js`：`calcSize({borderPercent})` → `{nW, nH + round(min(nW,nH)×pct/100)}`；显式画布尺寸；底栏文字 `12px→1em`、`24px→2em`，容器基准字号 `round(12×显示长边/900)`（≤900px 时与原 12px 恰好一致）
- 修复：巨型 logo（泛匹配选择器 `!important` 压过 logo 内联约束）；内容尺寸依赖旧 900px 画布

### P2 — Type C / D
- 同 A 方案迁移填满式；`type-C/D.css` 追加覆盖 + em 字号
- 字号镜像导出：`round(12 × 显示长边/900 × fontScale)`（C 竖图 0.7、D 竖图 0.85）

### P3 — Type B / E
- **B**：`calcSize` → 设计方形 `round(nH×1.1)`（仅竖图）；内容按**实际渲染方形** `frameWrapper.clientWidth/900` 缩放（fw 有 `overflow:hidden`，窄窗被 flex 收缩：900 视口 768→740、700 视口 672→540）；`updateBorderContent` 顶部统一清理 `.type-b-main-container` 残留（修复 B→其他样式泄漏）
- **B 圆角修订**：预览增加 `borderRadius = round(12×渲染方形/900)px`（与导出一致；此前预览从未实现）；`app.js updateBorder` 顶部统一清 `userImage.style.borderRadius` 防残留
- **E**：`calcSize` → `{短边, round(短边×1.5)}`；底栏高由显示高推导；基准字号 `max(8, round(24×显示宽/480))`（镜像导出 `scale=画布宽/480`）

### P4 — F–T 三批并入统一路径（仅 `app.js`）
- 批 1（F–J）：引入 `previewDesignCache` Map；统一路径补传 `naturalWidth/Height`；设计值归一 `design.canvasWidth ?? design.squareSize`
- 批 2（K–O）：迁移 K/L/M/N/O（M 旧分支本就 `init→reset` 顺序）
- 批 3（P–T）：统一路径扩至 A–T（全 20 样式）；`designSettings` 增补 `canvasRatioS/ratioT`；15 个 `typeXCachedSize` 变量与清空逻辑被 Map 取代（`clear()` + S/T `delete()`）
- 旧分支与旧实现全部以 `[LEGACY … e0bd5e5]` 注释保留（含原 if/else-if 连接行），保证可回滚
