# 历史版本记录（changelogs）

本目录存放 OneFrame NAS Edition 的历史更新记录（v1.08 起），两类文档成对出现：

| 系列 | 命名 | 说明 |
|------|------|------|
| Release 说明 | `release-vX.XX-nas.md` | 面向用户：版本亮点、升级说明 |
| 详细变更 | `VX.XX-NAS_CHANGES.md` | 面向维护：实现细节、文件清单、验证 |

## 收录范围
- **本目录**：v1.08 – v1.21（当前）
- **更早版本**（v1.00 – v1.09 记录及历史报告）：见 [`../archive/`](../archive/)
- **全版本日志**（含摘要）：仓库根目录 [`CHANGELOG.md`](../../CHANGELOG.md)
