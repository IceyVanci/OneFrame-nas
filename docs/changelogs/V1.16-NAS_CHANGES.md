# V1.16 NAS 变更记录

> 本版本为代码审查修复版：修复导出显示开关失效、Type E/B 预览一致性与健壮性，重构字体加载策略，修复 Docker 构建 manifest 遗漏 TypeN。不包含新边框样式。

## 🔧 Bug 修复

### 导出"显示开关"失效
用户关闭开关后，导出图片仍输出对应内容的问题：

| 开关 | 修复模块 | 说明 |
|------|----------|------|
| 署名 `showSignature` | A/C/D、F/G/H/L | A/C/D 门控由 `showSignature` 改为 `signatureText`；F/G/H/L 署名行补 `showSignature !== false` |
| 时间 `showTime` | J/K/M | 时间文本构造补 `settings.dateTime && settings.showTime` |
| Logo `showLogo` | M | Logo 绘制补 `settings.selectedLogo && settings.showLogo` |

### Type B 导出与预览布局不一致
- 导出端图片绘制宽度从 100% 可用区改为左侧 85% 区（与预览一致），修复右侧文字区坍缩、文字溢出
- 清除死赋值 `logoY`

### Type E 拖动监听器重复注册
- `init()` 每次被 `updateBorder()` 调用都会重复注册 `mousedown/mousemove/mouseup`，监听器无限累积
- 改为先 `removeEventListener` 再 `addEventListener`，幂等注册
- `window.handleLogoLoad` 全局泄漏改为模块内函数 + `addEventListener`，消除全局污染
- 非法日期（`new Date(脏值)`）不再抛 TypeError，返回空行

### Type E 预览参数/署名位置漂移
- 根因：参数块对齐依赖 `document.fonts.ready + getBoundingClientRect` 一次性测量，字体/布局时序导致位置偏高且不修正
- 改为确定性对齐：`marginTop = 2.333 × baseFontSize`，与导出端 `yearY = paddingTop + monthFontSize + 8*scale` 逐值一致
- 修正 `type-E.css`：`.type-e-month` 的 `em` 相对自身字号（2em）导致的间距 bug（0.333em→0.1665em）；`.type-e-param-line` 行高与导出 `textBaseline:top` 对齐（1.5→1 + margin-bottom）

### Type N 顶部 Logo 区首帧顺序耦合
- `updatePreview` 设置 `.type-n-top` 高度时元素尚未被 `updateContentPreview` 创建，首帧纵向高度不生效
- 改为 `updatePreview` 内先创建元素再设高度

## ⚡ 性能与健壮性

### 字体加载策略重构（新增 `js/styles/font-loader.js`）
- 14 个导出模块各自 `opentype.load` 3 个 8MB ttf（共 24MB），其中 12 个模块完全不用 opentype（仅 CSS fillText 渲染）
- 重构：抽公共 `font-loader.js`
  - `loadMiSansFonts()`：opentype 加载 **woff2**（约 15MB），模块级缓存 + Promise 去重，失败不抛出（返回 null 降级）
  - `ensureCssFontsReady()`：等待 CSS `@font-face` 就绪，供 fillText 渲染模块
- 仅 Type B（矢量轮廓 getPath）、Type E（年份测宽）保留 opentype；其余 12 个模块移除本地 `loadFonts()`
- 效果：一次导出不再下载/解析 24MB ttf；切换样式不再重复解析字体

### `ctx.roundRect` 兼容（新增 `js/styles/canvas-utils.js`）
- `roundedRectPath()`：`ctx.roundRect` 不存在时用 `arcTo` 手绘圆角路径
- 替换 Type B/F/G/L/M/N 六处调用，兼容老浏览器

### `generate-manifest.sh` 扫描式生成（修复 TypeN 遗漏）
- 原脚本硬编码 `TypeA...TypeM`，缺 TypeN → Docker 构建覆盖 manifest 后 Type N 卡片缩略图退化为固定图
- 改为从 Sample 文件名扫描提取样式类型，根治遗漏及未来新增样式的同类风险
