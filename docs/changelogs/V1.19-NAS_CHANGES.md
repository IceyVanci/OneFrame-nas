# V1.19 NAS 变更记录

> 本版本新增第 18 种边框样式 **Type R（Pentax 645N 胶片边缘打印）**：黑色胶片底 + 画面窗口 + 右侧胶片带竖排橙色参数打印，画布锁定 645 单帧比例，序号底边对齐图片下边缘。

## 🎨 新样式 Type R（胶片边缘打印）

### 布局规格

| 项 | 值 |
|----|------|
| 画布比例 | 横图 4:3、纵图 3:4（方向随原图；`ratio = isPortrait ? 3/4 : 4/3`） |
| 画布尺寸 | 高度受限：`canvasH = 原图高 / 0.84`；否则 `canvasW = 原图宽 / 0.89` |
| 画面窗口 left / top / width / height | 0.03 / 0.08 / 0.89 / 0.84（占画布宽/高） |
| 右侧胶片带宽 | 0.08 × 画布宽 |
| 底色 | `#000000` |
| 打印颜色 | `#E5742A` |
| 文字基准字号 | 0.022 × 画布宽（`baseFont`；内容过长时按需缩小） |
| 打印项（自顶向下） | 署名 / 日期 / 焦距 / 曝光偏差 / 光圈 / 快门 / 曝光模式 / 序号 |
| 文字方向 | 逆时针 90°（字宽方向竖向，字头朝右、自下而上读） |
| 字体 | `Doto`（Bold 700），回退 `MiSans`；字距 `0.04em` |
| 排版区间 | `windowTop`(0.08) → `windowTop + windowHeight`(0.92)，即图片上/下边缘 |

### 动态边缘等距排版（`computePrintLayout`）

预览与导出共用同一函数，返回 `{ fontSize, centers }`：

1. 只取非空项；**署名槽恒定存在**（含为空时），其余空项跳过。
2. 每项"预留长度"：用绑定字体（Doto）的 `measureText` 测量，含 `0.04em` 字距，换算为画布高比例。
3. 署名预留长度 = `signatureReserveChars(5) × 单字步进`（`charAdvanceEm = 0.6`），与署名实际字数无关。
4. 等分空白 `gap = (windowHeight − Σ预留长度) / (项数 − 1)`。
5. 自上而下：`top₀ = windowTop`，`topₖ₊₁ = topₖ + 预留长度ₖ + gap`。
6. 末项（序号）**底边恒等于图片下边缘**（0.92）；顶项（署名盒）顶边恒等于图片上边缘（0.08）。
7. 内容过长（`Σ预留长度 + (n−1)×minGapEm > windowHeight`）时**线性缩小字号**（`minGapEm = 0.6`），保证不溢出。

> 因署名用固定 5 字符盒，**其余各项位置不随署名长短变化**；相邻可见文字空白均相等。

### 署名预留盒

- 盒长度固定 = 5 字符；**盒顶贴图片上边缘**（0.08），盒底 = `0.08 + 5×单字步进`。
- 文字**以盒底为锚点向上排**（首字符在盒底）：
  - ≤5 字符 → 落在盒内（顶部留空）；
  - >5 字符 → 继续向上，超出 0.08 延伸到上方胶片黑边。
- 署名为空时仍保留该盒，其余项位置不变。

### 参数来源与格式化

| 项 | 来源 | 显示 |
|----|------|------|
| 署名 | 编辑面板（英文） | 原样，预留 5 字符盒 |
| 日期 | 原生 `<input type="date">`，EXIF `DateTimeOriginal` 预填，无则今天 | `YY/MM/DD` |
| 焦距 | EXIF **物理焦距** `getPhysicalFocalLength` | 数值（去 mm） |
| 曝光偏差 | EXIF `ExposureBiasValue`，`formatExposureBias` | `0.0Ev` / `+0.7Ev` / `-0.3Ev` |
| 光圈 | EXIF `FNumber` | 补 `F` 前缀 |
| 快门 | EXIF `ExposureTime` | 原样 |
| 曝光模式 | 下拉（`--` / `M` / `P` / `Av` / `Tv`），`getExposureModeLabel` 预填 | 原样 |
| 序号 | 编辑面板 | 默认 `01` |

### 画面窗口与拖动

- 窗口内照片 `object-fit: cover`，按归一化偏移 `offset{x,y} ∈ [-1,1]` 设置 `object-position`。
- 鼠标拖动（`mousedown/mousemove/mouseup`）更新偏移；导出端按同一归一化偏移用 `drawImage` 裁剪，保证预览/导出一致。

### 编辑面板

- 显示：署名（+ 提示「点阵字体（Doto）仅支持英文署名」）+ 序号 / 日期 / 曝光模式 / 快门 / 光圈 / 曝光偏差 / 焦距。
- 隐藏：比例、边框、Logo、设备型号、原拍摄参数、时间、文字颜色、厂商、胶片、Type Q 署名区等。
