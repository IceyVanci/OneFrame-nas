# V1.20 NAS 变更记录

> 本版本新增第 19、20 种边框样式 **Type S（留白排版 / 参考图）** 与 **Type T（满幅无边框 / 参考图）**：两者共用一套"参考图/杂志排版"文字系统（左上两行文字 + 右侧竖排日期与三角标记 + 右下参数行），支持画布比例切换（1:1 / 1:1.35 竖）与图片主色取色。

## 🎨 新样式 Type S（留白排版）

### 布局规格

| 项 | 值 |
|----|------|
| 画布 | 白色 `#ffffff`，**画布比例可切换**：`1:1` / `1:1.35`（竖），`ratio = isPortrait ? 1.35 : 1` |
| 画布尺寸 | 照片恒为画布宽 82% 的正方形，取原图短边为照片边长，`canvasWidth = shortSide / 0.82` |
| 照片区 | 画布宽 82% 正方形，**水平垂直居中**（`getPhotoRect` 计算） |
| 照片适配 | `object-fit: cover`，按归一化偏移 `offset{x,y} ∈ [-1,1]` 设置 `object-position`，可二维拖动裁剪 |
| 左上文字 left / top | 0.045 × 画布宽 / 0.02 × 画布高，行高 1.6，字距 0.06em |
| 左上文字字号 | 0.017 × 画布宽（下限 7px） |
| 右侧日期 right | 0.028 × 画布宽，字号 0.018 × 画布宽，字距 0.25em，**垂直居中** |
| 右侧标记 | 倒三角：上平边、下收尖、尖端渐隐（`clip-path` + `mask-image`），宽 1em / 长 5em |
| 右下参数 right / 中心 Y | 0.09 × 画布宽 / 0.96 × 画布高，字号 0.02 × 画布宽，字距 0.25em |
| 字体 | `MiSans`（状态栏 400） |

### 文字内容

- **左上（自上而下两行）**：第一行（默认空，占位示例 `IN FRAME`）+「`PHOTO BY {handle}`」；两行都为空时整体不显示
- **右侧竖排日期**：`YYYYMMDD`（输入 `YYYY-MM-DD`，`formatDateS` 转换），`writing-mode: vertical-rl`，其下为倒三角标记
- **右下参数行**：`ISO {iso} | {focal}mm | F/{f} | {shutter}s`（EXIF 预填，可手改），空值隐藏对应段

### 文字颜色（默认：图片主色）

- 预设四选：**图片主色（dominant，默认）/ 黑 `#000000` / 琥珀 `#E5742A` / 自定义**
- 自定义：原生选色器 `#typeSColorPicker` + **「点选图片取色」按钮**（点击后面向原图片十字光标，点击取色）
- 主色提取复用 `js/utils/dominant-color.js` 的 `getDominantColor()`（32×32 采样 + 4bit/通道分桶量化，按 `img.src` 缓存）

## 🎨 新样式 Type T（满幅无边框）

### 布局规格

| 项 | 值 |
|----|------|
| 画布 | **照片铺满整张画布（无白边）**，画布 = 照片比例，比例可切换：`1:1` / `1:1.35`（竖） |
| 画布尺寸 | `canvasHeight = min(原图高, 原图宽 × 高宽比)`，不放大（`calcSize`） |
| 照片区 | 满幅（画布整幅），`object-fit: cover`，可二维拖动裁剪 |
| 左上 / 右侧日期 / 右下参数 | 布局常量与 Type S 相同（`TYPE_T_LAYOUT`） |
| 文字阴影 | `0 0 0.12em rgba(0,0,0,0.45)` + `0 0.05em 0.08em rgba(0,0,0,0.35)`，导出端 `ctx.shadowBlur = 0.003×W` / `shadowOffsetY = 0.0012×W`，保证压在照片上可读 |

### 文字内容

- 与 Type S 完全一致：左上两行（第一行 + `PHOTO BY {handle}`）、右侧竖排日期 `YYYYMMDD` + 倒三角标记、右下参数行 `ISO | mm | F/ | s`

### 文字颜色（默认：白）

- 预设四选：**白 `#ffffff`（默认）/ 图片主色（dominant）/ 琥珀 `#E5742A` / 自定义**
- 自定义：原生选色器 `#typeTColorPicker` + 「点选图片取色」按钮

## 编辑面板

- **Type S 显示**：画布比例（`#canvasRatioS`）+ 文字（第一行 `#topLineS` / PHOTO BY `#photoByS` / 日期 `#dateS`）+ 右下参数（`#isoS` `#focalS` `#fNumberS` `#shutterS`）+ 文字颜色（预设 + 选色器 + 点选按钮）
- **Type T 显示**：照片比例（`#ratioT`）+ 文字（`#topLineT` `#photoByT` `#dateT`）+ 右下参数（`#isoT` `#focalT` `#fNumberT` `#shutterT`）+ 文字颜色（预设 + 选色器 + 点选按钮）
- **隐藏项（两者一致）**：比例（传统 `#aspectRatioSection`）、边框颜色、Logo 选择、设备型号、原拍摄参数、拍摄时间、通用文字颜色、厂商、胶片、Type Q 署名区、Type R 打印区、对方分区（S 隐藏 `#typeTSection`，T 隐藏 `#typeSSection`）、通用署名区
- 所有显示开关（Logo / 机型 / 参数 / 时间 / 署名）隐藏

## EXIF 预填（全部可手输覆盖）

- Type S 输入框：`isoS` ← `ISOSpeedRatings`；`focalS` ← **物理焦距** `getPhysicalFocalLength`（去 mm）；`fNumberS` ← `FNumber`（去 F 前缀）；`shutterS` ← `ExposureTime`；`dateS` ← `DateTimeOriginal`（`YYYY-MM-DD`），无则今天
- Type T 输入框：`isoT` / `focalT` / `fNumberT` / `shutterT` / `dateT` 同上

## 拖动裁剪

- 照片区 `object-fit: cover`，鼠标拖动（`mousedown/mousemove/mouseup`）更新归一化偏移 `offset{x,y} ∈ [-1,1]`，`object-position` 百分比 = `50 + offset × 50`
- 导出端按同一归一化偏移用 `drawImage` 裁剪（`drawOffset = x - maxOffset × (1 + offset.x)`），保证预览/导出一致
- 超过 `5px` 可拖动范围时显示拖动提示「拖动选择显示区域」

## 首页缩略图

- Type S / T **不参与随机缩略图**，固定使用自身样本：
  - Type S：`Sample/04474-TypeS-sample_compressed.jpeg`（由原片 `DSC04474` 压缩而来）
  - Type T：`Sample/04510-TypeT-sample_compressed.jpeg`（由原片 `DSC04510` 压缩而来）
- `thumbnail-selector.js`：Type S/T 与 Type O/P/Q/R 一致，`buildStyleThumbnailMeta` 返回 null 回退卡片占位，不再占用独立样本位
