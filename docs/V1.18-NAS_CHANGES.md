# V1.18 NAS 变更记录

> 本版本新增第 16、17 种边框样式 **Type P（参数布局）** 与 **Type Q（简洁布局）**：前者机型+品牌 Logo+参数胶囊、照片按原图比例完整显示；后者四边主色边框 + 右下 "Foto by" 署名。

## 🎨 新样式 Type P（参数布局）

### 布局规格

| 项 | 值 |
|----|------|
| 照片区 left / top / width / height | 3.5% / 4% / 93% / 76.5%（底部 19.5% 文字区） |
| 画布尺寸 | 宽=原图/0.93，高=原图/0.765 |
| 文字基准字号 | 0.030 × 画布宽 |
| 第 1 行（机型+分隔线+Logo）中心 Y | 0.852 × 画布高 |
| 参数胶囊中心 Y / 标签中心 Y | 0.912 / 0.952 × 画布高 |
| 胶囊：字号 / 高 / 水平内边距 / 间距 / 圆角 | 0.72× / 1.75× / 0.75× / 1.2× / 22% × 胶囊高（均×基准字号） |
| 分隔线 | 高 1.0×基准、宽 max(1, canvasW×0.0012) |
| Logo | 高 1.15×基准，沿用现有 Logo 选择器（`selectedLogo`），未选则只显机型 |
| 标签（s / ISO / mm / f） | 0.42×基准，#999999 |

- 第 1 行：**机型**（Semibold #000）→ 细分隔线 → **品牌 Logo**（彩色 SVG），水平居中
- 第 2 行：**4 个圆角参数胶囊**（细灰描边、白底）+ 下方浅灰小标签
- 参数取自现有 EXIF 字段（快门 / ISO / 焦距（去 mm 后缀）/ 光圈），顺序 s → ISO → mm → f，空值隐藏对应胶囊
- **照片完整显示无裁切**：预览端按显示宽度内联 px 精确构造照片区（`photoW = round(displayW×0.93)`、`photoH = round(photoW×H/W)`、`objectFit: fill`）；导出端全图 1:1 `drawImage`（`canvasW=W/0.93`、`canvasH=H/0.765`）。画布公式与边距常量同源（`TYPE_P_LAYOUT`），预览/导出一致
- 预览胶囊全部内联 px，与导出公式逐项一致（字号/内边距/圆角/描边/间距/标签/分隔线）

### 编辑面板（顺序：Logo → 设备型号 → 拍摄参数）

- **Logo**：沿用现有 Logo 选择器
- **设备型号**：`#cameraModelInput`，EXIF 自动读取，placeholder `自动从EXIF读取`
- **拍摄参数**：`#showParams` 开关，控制第 2 行胶囊+标签显隐
- 边框颜色/高度、比例、时间、文字颜色、胶片、署名等隐藏

## 🎨 新样式 Type Q（简洁布局）

### 布局规格

| 项 | 值 |
|----|------|
| 四边边框 | 等宽 2.5% × 画布宽，颜色 = **图片主色** |
| 照片区 | 95% × 95% 居中 |
| 画布尺寸 | 宽=原图/0.95，高=原图/0.95 |
| 署名 | "Foto by {署名}"，Semibold，字号 0.021 × 画布宽 |
| 署名位置 | 右缩进 3.5% × 画布宽，中心 Y 0.953 × 画布高（叠照片内右下角） |
| 署名颜色 | 三选一：黑 / 白 / 图片主色（`#qSignatureColor` 隐藏输入 + 预设按钮） |
| 署名开关 | `#switchSignatureQ`，可隐藏署名 |

- 边框颜色与署名"主色"选项均取自同一 `getDominantColor(img)`

### 主色提取 `js/utils/dominant-color.js`

- 图片缩绘到 32×32 canvas，按 4bit/通道（16 级 ×3 = 4096 桶）分桶统计
- 取样本数最多的桶，对桶内像素求平均 → `#rrggbb`
- 结果按 `img.src` 缓存（`Map`），同一张图只计算一次
- 失败回退 `#ffffff`

### 编辑面板

- 显示：署名 + Type Q 署名区（颜色预设按钮 + 开关）
- 其余（Logo/参数/时间/边框颜色/比例/胶片等）隐藏
