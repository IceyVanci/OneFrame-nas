# OneFrame NAS Edition v1.08 — v1.13 Release Notes

**发布日期范围**：2026-06-29 ~ 2026-07-02
**支持样式**：13 种（Type A ~ Type M）
**基础镜像**：nginx:alpine

---

## v1.08（2026-06-29）

### 🎉 新功能

**Type K — 左下角 Logo + 双行文字**
- Logo 在底部左下角，右侧显示两行文字
- 第一行：署名 + 日期；第二行：机型 + 拍摄参数
- 照片 100% 填满画布，纵向图片字号增大 50%

**Type L — 高斯模糊背景**
- 将白色外框替换为照片的高斯模糊版本
- 清晰照片 92%×80% 居中
- 默认白色文字，支持黑/灰/白选择

**Type J 编辑面板改进**
- 设备型号输入框可见，方便手动修改

---

## v1.09（2026-06-29）

### 🎉 新功能

**主界面图片墙重构**
- 从单列纵向排列重构为 3 列瀑布流图片墙
- 移除参数/海报标签栏，所有样式同时显示
- 布局铺满窗口宽度，自适应屏幕

**Type K/L 编辑面板改进**
- 显示设备型号输入框

**文件名大写化**
- 48 个样式文件名从小写改为大写（`type-a` → `type-A`）
- CSS 类名、data-style 属性保持小写不变

---

## v1.10（2026-06-29）

### 🎉 新功能

**编辑器动态背景色**
- 导入图片后，编辑器预览区背景色自动根据图片主色调生成深色版本
- 暖色调照片 → 深橙/棕色背景；冷色调 → 深蓝色；绿色植物 → 深绿色
- 技术实现：10×10 canvas 采样，平均 RGB × 0.4 系数压暗

---

## v1.11（2026-06-30）

### 🎉 新功能

**Type M — 模糊边框 + 顶部 Logo + 底部文字**
- 基于 Type I + Type J + Type L 的混合设计
- 照片 90%×90% 居中，四条边等高模糊背景（各 5%）
- 顶部 Logo + 底部署名 + 参数行三栏
- 导入图像应用 12px 圆角

### 🔧 Bug 修复

**Type L 导出模糊背景缩放修复**
- 修复导出图片模糊背景边缘黑边/透明边问题
- 在 `drawBlurredBackground` 中添加 1.5x 缩放，与预览端 CSS 一致

**关于界面调整**
- GitHub 链接指向 OneFrame-nas 项目
- 添加 Bilibili 和 Instagram 链接

---

## v1.12（2026-06-30）

### 🔧 Bug 修复

**Type E 图片拖动边界修复**
- 修复图片拖动超出画布边界的问题

**Type E 导出偏移方向修复**
- 修复导出图片偏移方向与预览不一致的问题

---

## v1.13（2026-07-01）

### 🎉 新功能

**首页缩略图随机选取**
- 每次刷新页面，每个样式卡片从对应样式的样本图片中随机选取一张显示
- 避免用户每次看到相同的首页预览

**Manifest 清单法性能优化**
- 新增 `sample-manifest.json` 清单文件
- 1 次 fetch 请求替代 2,574 次 HEAD 请求（13 样式 × 198 张图片）
- 首页加载从 2-3 秒降至 <500ms

### 🔧 Bug 修复

**缩略图闪烁修复**
- 修复刷新页面时缩略图闪烁两次的问题

**导出焦距单位修复**
- 修复部分样式导出图片遗失焦距单位 `mm` 的问题
