# V1.17 NAS 变更记录

> 本版本新增第 15 种边框样式 **Type O（胶片参数·机身大字·底部水印）**，含胶片品牌/型号数据与多级下拉编辑面板，并优化纵向图片白边。

## 🎨 新样式 Type O（胶片参数 · 机身大字 · 底部水印）

### 布局规格

| 项 | 横图 | 纵图 |
|----|------|------|
| 照片区 left / width | 8% / 84% | 9.5% / 81%（左右白边减半） |
| 照片区 top / height | 6% / 68% | 6% / 76.7%（底部白边减 1/3） |
| 文字区 top / height | 79% / 15% | 86% / 10% |
| 水印带 top / height | 94% / 6% | 96% / 4% |
| 画布尺寸 | 宽=原图/0.84，高=原图/0.68 | 宽=原图/0.81，高=原图/0.7667 |

- 照片区：2px 黑色描边（边框色可调）、0 圆角、cover 填满
- 三行文字（均水平居中，第 1+2 行组在文字区内垂直居中）：
  1. **胶片型号**：`0.80 × 机身字号`，MiSans Normal，#333333
  2. **厂商 + 机型**：`0.030 × 画布宽`，MiSans Semibold，#000000
  3. **署名水印**：`0.36 × 机身字号`，黑色，底部水印带
- 预览端按显示宽度、导出端按画布宽度同比例缩放，预览/导出一致

### 编辑面板（顺序：胶片 → 厂商 → 设备型号 → 署名）

- **胶片**：`#filmBrand` 品牌下拉（11 个胶片品牌）→ `#filmStyle` 型号 **可下拉可手输**（`<input list="filmPresets">`，datalist 按品牌筛选）
- **厂商**：`#manufacturerSelect`（13 家厂商精简列表，含相机+胶片品牌），用于第 2 行"厂商 + 机型"拼接
- **设备型号**：纯手输，**不读取 EXIF**（厂商同样不自动选中）
- **署名**：沿用 `signatureText`，水印显示 `© 署名`
- 边框颜色：照片描边色，进入 Type O 默认 `#000000`
- 其余（边框高度/比例/Logo/拍摄参数/时间/文字颜色/开关）隐藏

### 数据文件 `films.json`

- 结构：`{ version, manufacturers[], films: { 品牌: [型号...] } }`
- 厂商列表 13 家：Canon、Kodak、Fujifilm、Nikon、Leica、Hasselblad、Pentax、Olympus、Rollei、Ilford、Cinestill、Lucky、Fomapan
- 胶片表 11 品牌 60 款（Kodak/Fujifilm/Ilford/Cinestill/Lomography/Agfa/Rollei/Adox/Orwo/Lucky/Fomapan）
- 加载失败回退空表，不影响其他样式

### 首页缩略图

- Type O **不参与随机缩略图**，固定显示自身样本 `Sample/001-TypeO-sample_compressed.jpeg`
- `thumbnail-selector.js` 写入循环改为：样式无随机分配时回退 `data-fallback-src`（通用化）
